# 📷 UrbanLens-Digital Photo Trading Platform

A web platform that allows users to **upload, trade, and monetize digital photographs**. Designed for photographers and buyers to interact seamlessly, the platform supports secure logins, wallet-based payments, and a fully responsive interface.

---

## 🚀 Features

- 📤 Upload and showcase high-quality photographs
- 🔄 Trade or purchase photos using in-app wallet system
- 🔐 Secure user authentication and profile management
- 💳 Wallet-based payment integration for easy transactions
- 📱 Fully responsive UI for mobile and desktop
- 👤 Separate workflows for photographers and buyers
